## Project
**CosmOS: The Divine Repair Tool** — An incremental/idle game fusing Windows 98/XP retro OS aesthetics with divine cosmic mythology. You play a retired deity's successor, repairing a broken universe through an ancient Sacred OS interface.

**Core aesthetic:** Beveled window chrome + celestial pulsing cores. Neither purely retro nor purely cosmic — a balanced hybrid where clicking buttons is a ritualistic act.
